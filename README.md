MYSELLAR 

This project focuses on analyzing the sales operations of a multinational retail store, Mysellar, with the goal of identifying regional performance trends and uncovering opportunities for growth. 

Using sales, revenue, and logistics data segmented by country and region, the analysis evaluates key performance metrics such as total revenue, profit, shipping time, and correlation with economic indicators like GDP. 

Interactive visualizations were built in Tableau, enabling stakeholders to explore regional trends and make data-driven decisions. The findings provide actionable insights to support strategic expansion, optimize logistics, and tailor regional sales approaches.
